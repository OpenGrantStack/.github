## How completion is scored

Every repo is scored 0–100% across eight measurable signals. No self-assigned badges — the number is computed, not claimed.

| Signal | Weight | Check |
|--------|--------|-------|
| Has description | 5% | GitHub metadata |
| Has topics/tags | 5% | GitHub metadata |
| Has LICENSE | 10% | File exists |
| README > 500 bytes | 10% | File size |
| Has tests | 15% | `tests/`, `*.test.*`, `*_test.*`, etc. |
| Has CI workflows | 15% | `.github/workflows/*` |
| Commit in last 90 days | 20% | Commit history |
| Has release/tag | 20% | GitHub releases or tags |

**Tiers:** Concept (0–24) · Prototype (25–49) · Active (50–74) · Production-Ready (75–89) · Mainnet (90–100)

Run the scanner yourself:

```bash
gh auth login
./scripts/scan-org.sh
# → writes status/report.md and status/<repo>.json
```

🌐 OpenGrantStack

Open infrastructure for transparent, auditable, community‑driven grantmaking.

OpenGrantStack is a modular, open‑source platform designed to modernize how grants are created, reviewed, awarded, and audited.  
We combine secure automation, transparent governance, contributor analytics, and open standards to empower organizations, funders, and communities to collaborate with confidence.

Our mission is simple:  
Make grantmaking fair, efficient, and radically transparent — for everyone.

---

🚀 What We’re Building

OpenGrantStack is a full ecosystem of interoperable services, including:

- Webhook Receiver — Secure GitHub App event ingestion  
- Contribution Ledger — Immutable, audit‑ready contribution tracking  
- GrantReady SaaS — Front‑end for applicants, reviewers, and admins  
- GrantReady Cloud — Backend workflows, storage, and document processing  
- GrantReady Hub — Analytics, dashboards, and governance insights  
- Integrations Service — Email, Slack, Discord, signing, and external APIs  
- Design System — Unified UI components and accessibility foundations  
- SDKs (Python + JS) — Developer‑friendly interfaces for automation  
- CLI — Tools for contributors, maintainers, and grant teams  
- Governance & Compliance — Policies, ethics, risk, and operational standards  
- Docs Site — Public documentation, onboarding, and architecture guides  

This ecosystem is designed for scalability, auditability, and long‑term sustainability.

---

🧱 Our Architecture Philosophy

OpenGrantStack is built on five core principles:

1. Transparency by Default
Every contribution, workflow, and decision is traceable and auditable.

2. Modular by Design
Each service is independent, replaceable, and easy to integrate.

3. Governance‑First
Policies, ethics, and compliance are first‑class citizens — not afterthoughts.

4. Developer‑Friendly
SDKs, examples, templates, and automation make adoption frictionless.

5. Community‑Driven
Open source is not a license — it’s a governance model.
